# DMSM (Django Minecraft Server Monitor)

DMSM — это веб-приложение для мониторинга серверов Minecraft, сбора статистики онлайна и предоставления игрокам удобного веб-профиля с графиками их игровой активности.

## Стек технологий
- **Backend**: Python 3, Django 5, PostgreSQL
- **Frontend**: HTML5, Vanilla JS, TailwindCSS, D3.js (для графиков)
- **Интеграции**: RCON (для связи с сервером Minecraft), Whitenoise (для раздачи статики)

## Архитектура
Проект разделен на четыре основных приложения (apps):
- **core**: главная страница, общая статистика онлайна сервера;
- **users**: система авторизации, профили игроков, привязка аккаунтов Minecraft к веб-аккаунтам;
- **monitor**: фоновый процесс для мониторинга сервера по Pterodactyl API/RCON, сбора данных о сессиях игроков и онлайне;
- **api**: REST API для асинхронной подгрузки статистики на Frontend.

## Инструкция по локальному запуску

1. **Клонируйте репозиторий и перейдите в папку проекта:**
   ```bash
   git clone <url-репозитория>
   cd DMSM
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройте переменные окружения:**
   Скопируйте файл `.env.example` в `.env` и подставьте свои значения:
   ```bash
   cp .env.example .env
   ```

5. **Примените миграции базы данных:**
   ```bash
   python manage.py migrate
   ```

6. **Соберите статику:**
   ```bash
   python manage.py collectstatic
   ```

7. **Запустите фоновый монитор (в отдельном терминале):**
   ```bash
   python manage.py run_monitor
   ```

8. **Запустите веб-сервер:**
   ```bash
   python manage.py runserver
   ```
   Сайт будет доступен по адресу: http://127.0.0.1:8000/
