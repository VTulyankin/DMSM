# Техническое задание на проект: Система мониторинга и анализа активности игроков для сервера Minecraft с визуализацией индивидуальной статистики игровых сессий

## 1. Цель проекта
Создание веб-сервиса для автоматизированного сбора, хранения и анализа активности игроков на сервере Minecraft. Система предназначена для отслеживания индивидуальных игровых сессий и предоставления публичной визуальной аналитики.

## 2. Роли пользователей (Use Cases)
* **Гость (а также зарегистрированный, но не привязанный к игровому аккаунту пользователь):** просмотр публичной страницы сервера, просмотр глобальной статистики сервера в виде графика (статус работы, динамика количества игроков и список игроков онлайн в выбранный момент времени)
* **Пользователь (с привязанным аккаунтом Minecraft):** просмотр списка всех игроков сервера, доступ к профилям конкретных пользователей с детальной статистикой и интерактивными графиками их индивидуальных игровых сессий, дополнительной информацией
* **Администратор:** суперпользователь, имеющий доступ к панели управления веб-сервисом и управлению базой данных

## 3. Модели данных (сущности)
Проект использует СУБД PostgreSQL для эффективной работы с частыми операциями записи и агрегациями временных рядов. Секретные данные для подключения к серверу (ссылка, токен API, ID сервера) хранятся в конфигурационном файле `.env` в целях безопасности
* **Player (Игровой аккаунт Minecraft)**:
   * `uuid`: идентификатор Minecraft
   * `nickname`: актуальный никнейм
   * `first_seen`: время первого появления игрока на сервере
* **Session (Игровая сессия)**:
   * `player` (`ForeignKey` к `Player`)
   * `login_time`: время начала сессии
   * `logout_time`: время конца сессии
* **Server (Состояние сервера)**:
   * `timestamp`: временная отметка
   * `is_online`: статус работы сервера на момент отметки
   * `player_count`: общее количество игроков на момент отметки
   * `service_mode`: режим работы сервиса мониторинга на момент отметки
* **UserProfile (Аккаунт на сайте)**:
   * `user`
   * `player` (`ForeignKey` к `Player`, может быть пуст до момента привязки)

## 4. Ключевой функционал
* **Каталог и поиск**: пользователь может просматривать список всех когда-либо заходивших на сервер игроков, искать конкретного игрока по никнейму
* **Визуализация профиля**: на странице конкретного игрока отображается интерактивный график, демонстрирующий длительность и историю его индивидуальных игровых сессий
* **Глобальный мониторинг**: пользователь видит на главной странице текущий статус работы сервера и глобальный график динамики одновременных подключений
* **Обновление данных**: система непрерывно анализирует поступающий поток данных с сервера, автоматически формирует записи о начале и завершении игровых сессий, регистрирует триггеры внутриигровых событий и обновляет статус доступности сервера.

## 5. Внешние интеграции / Аналитика
* **Интеграция:** использование Pterodactyl API для подключения к консоли сервера и получения логов в реальном времени
* **Обработка данных:** потоковый парсинг логов для классификации игровых событий, расчет длительности сессий
* **Визуализация:** использование библиотек для отрисовки интерактивных диаграмм
